# 🎬 TubeFetch

> **Версия:** `v1.0 First Release`  
> Минималистичный и быстрый инструмент для валидации и скачивания видео с YouTube на базе `yt-dlp`.

---

## 📌 О проекте

**TubeFetch** — это модульная утилита на Python, предназначенная для удобной загрузки видео и аудиоматериалов с YouTube. Проект включает в себя многоуровневую валидацию ссылок (синтаксический regex-анализ и сетевая проверка доступности ролика без старта загрузки) с интеграцией cookies из браузера.

---

## ✨ Текущие возможности

- [x] **Строгая валидация URL:** Проверка форматов `watch?v=`, `youtu.be/`, `shorts/` через регулярные выражения.
- [x] **Проверка доступности (Pre-check):** Анализ доступности видео до начала фактического скачивания.
- [x] **Использование Cookies:** Автоматическое подключение авторизационных сессий и куки для обхода ограничений и скачивания в высоком качестве.
- [x] **Модульная архитектура:** Разделение логики загрузки (`downloads.py`) и верификации (`verifications.py`).
- [x] **Улучшенный CLI:** Более читаемый интерфейс с понятными подсказками и подтверждениями.
- [x] **Проверка пути скачивания:** Повторный ввод, если папка указана неверно.

---

## ⚙️ Системные требования

- **Python:** 3.10 или новее
- **FFmpeg:** Рекомендуется для объединения видео/аудио потоков максимального качества (1080p+, 4K) и конвертации в MP3.
  - *Windows:* `winget install Gyan.FFmpeg` или скачать с [ffmpeg.org](https://ffmpeg.org/)
  - *Linux (Ubuntu/Debian):* `sudo apt install ffmpeg`
  - *macOS:* `brew install ffmpeg`

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone -b develop https://github.com/Giggichk/TubeFetch.git
cd TubeFetch
```

### 2. Создание и активация виртуального окружения
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```
*(Если `requirements.txt` еще не создан: `pip install yt-dlp`)*

### 4. Запуск
```bash
python main.py
```

## 🗺️ Дорожная карта

- [ ] 🌐 **Скачивание в регионах с ограничениями / без VPN:** Внедрение смены `player_client` (`android`, `ios`) и поддержка Proxy (HTTP/SOCKS5).
- [x] 🎛️ **Выбор качества и форматов:** Интерактивное меню выбора разрешения (4K, 1080p, 720p, 480p) и извлечения чистого аудио (MP3/M4A).
- [ ] 📑 **Поддержка плейлистов и очередей:** Пакетное скачивание по ссылкам из файлов.
- [x] 💻 **Интерфейс:** Полноценный CLI.
